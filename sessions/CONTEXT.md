# /sessions — running it with real people

## What this workspace is for
Facilitator preparation, run logs, generated one-pagers and reports, and what to change next. This is where the ROI evidence accumulates: time to decision, participation balance, lens coverage, and whether the committed action happened.

## Files
- `<roomCode>.json` — engine-written manifests (do not hand-edit).
- `YYYY-MM-DD-group-method.md` — facilitator log for one run: who, problem, what broke, what to change. Written within a day of the session while it is fresh.
- `reports/` — generated one-pagers and session reports, copied here by the engine.
- `facilitator-checklist.md` — pre-session checklist (grows from runs; first version below).

## Process
1. Before: pick a real problem the group actually has (not a toy), confirm 4–6 people, one device each, and a projector or shared screen for the room view. Load the method, create the room, test-join from a phone.
2. During: you own the overrides. Use them; log why. Watch the stuck flags rather than the timer.
3. After: run the report, write the log, and file the follow-up date from the commit block in your calendar. At 30 days, note whether the first action happened; that line is the whole ROI case.

## Facilitator checklist v0
- Problem sentence drafted in advance as a fallback (Frame block can burn five minutes on wording).
- Room code on the screen before people sit down.
- Know the override path: which button, and that it asks for a reason.
- Have one extension in mind for the green hat; it is the block that runs long.

## What good looks like
- The group leaves with one committed action and an owner, inside the time budget, without you having to talk for more than a few minutes total.
- The report says something the group did not already know about themselves (usually participation balance).

## What to avoid
- Running the first sessions with people who are testing the tool rather than solving a problem; you learn nothing about the method.
- Editing manifests by hand to "fix" a session. Log it and fix the engine.
