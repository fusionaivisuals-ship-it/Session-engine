# Current thinking methods

The catalog follows `thinking-methods-app-copyright-guidance.md`. Instructions, coaching, rubrics and fictional examples are written for this project. This describes product implementation, not legal clearance.

| Method | Session workflow | Output |
|---|---|---|
| Pros-and-cons analysis | Arguments on both sides → importance and confidence → safeguards and conditions | A reasoned, conditional choice |
| Five Whys | Immediate condition → contributing links → alternatives → reachable condition and check | A supported causal chain or an explicit evidence gap |
| Cause-and-effect / fishbone analysis | Choose categories → attach causes and subcauses → prioritize distinguishing checks | A textual category/branch map and an investigation plan |
| Decision matrix | Define scale and weights → establish comparable options → score, calculate and challenge | Weighted comparisons and a sensitivity check, recorded as text |
| Brainstorming with prioritization | Independent ideas → testable candidates → reasoned ranking | One selected trial and its main uncertainty |
| Hypothesis testing | Competing explanations → predictions → test design → observations or missing data | A test plan or an appropriately limited interpretation |

All six support solo and group sessions using the same frame, private-input, reveal, converge, commit and report blocks. No fixed branded roles are used. The engine retains generic fixed-role support for future configurations.

Five Whys must not manufacture additional causes to reach five answers. Fishbone branches are hypotheses. Matrix totals do not remove uncertainty. Hypothesis testing does not fabricate results or force an experiment to finish during the workshop.
